# Ethics and Boundaries

FlowScribe is intended for personal learning, accessibility, research notes, and lawful information processing.

## Allowed Direction

- Transcribe local files owned by the user or available for lawful personal use.
- Transcribe recordings created by the user for private notes.
- Export transcripts for personal review and AI-assisted analysis.

## Not a Goal

- Bypassing DRM.
- Cracking client applications.
- Redistributing copyrighted subtitles or transcripts without permission.
- Building bulk scraping workflows for protected content.

## Client Application Strategy

For future support of videos played in desktop applications, FlowScribe should prefer user-controlled system audio capture instead of attempting to read private application internals.
